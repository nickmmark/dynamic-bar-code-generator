Example: "0" • code value 16 • pattern 123122

Pattern 123122 means: Bar×1, Space×2, Bar×3, Space×1, Bar×2, Space×2. Bars are black rectangles; spaces are the white gaps. Each number is a multiple of the narrowest “module”.
